# PROJECT OVERVIEW

Build a secure production-grade “Intimation” bulk mail system integrated inside my existing Next.js website hosted on Railway.

Main domain:
https://redalertsol.com

This is NOT a public feature.

This is a hidden admin-only internal communication system for sending personalized PDF emails to clients.

Expected volume:
- less than 50 emails/day

Main goals:
- personalized PDF attachments
- editable templates
- multiple company profiles
- delivery tracking
- strong authentication/security
- Railway-compatible deployment
- Resend email provider
- future Gmail provider switching support
